PROJECT CASE

智能人脸识别考勤终端

从人脸算法到终端、云端和小程序的完整系统

ROLE项目负责人 PERIOD2022.09 — 2023.12 STACKPyTorch · Qt · OpenCV · Linux · FPGA + ARM

项目概述

基于 FPGA + ARM 架构实现楼宇环境监测与人脸识别考勤一体终端。项目不是单独的人脸识别 Demo，而是从算法、终端应用、后台管理、云端数据到微信小程序形成完整产品链路。

主要工作

  • 系统总体方案设计
  • 轻量级人脸检测与识别算法设计、训练
  • Linux 下 Qt + OpenCV 应用开发并移植 ARM
  • 考勤系统、后台管理系统和微信小程序平台开发
  • 多传感器数据采集、处理、传输及云服务器开发
  • 样机硬件搭建与系统联调

结果与产出

  • 人脸识别精度不低于 99%
  • 识别时间不高于 1 秒
  • 实现活体识别、考勤记录、公告、数据上云和 Web 可视化
  • 制作考勤样机 5 台并在实验室试运行
  • 形成 SCI 论文与发明专利成果
